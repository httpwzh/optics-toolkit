公式与适用范围

复参数 q（嵌入 M²，x、y 各一套）：q(z) = (z − z_w) + i·zR，zR = π w₀² / (M² λ) 自由传输（展开光程）：q₂ = q₁ + d 薄透镜：1/q₂ = 1/q₁ − 1/f（凸透镜 f > 0，凹透镜 f < 0），fx = fy = f 球面反射镜（展开为等效透镜）：f = R/2（凹面镜），f = −R/2（凸面镜） 斜入射角 θ（相对镜面法线，折转角 2θ）：子午 f_t = f·cosθ，弧矢 f_s = f/cosθ 水平折叠：fx = f_t，fy = f_s；竖直折叠：fx = f_s，fy = f_t 光斑半径：w(z) = w₀ √[1 + ((z − z_w)/zR)²]，R(z) = (z − z_w)[1 + (zR/(z − z_w))²] 口径透过率（椭圆光斑 / 圆口径，斜入射时口径投影为 a·cosθ × a 的椭圆）： T = 1 − (1/2π)∫₀^{2π} exp[−2 / (u²cos²φ + v²sin²φ)] dφ，u = w_x/a_x，v = w_y/a_y 元件效率 = T × 反射率（透镜仅计 T）；峰值功率密度 I₀ = 2·P·η / (π·wx·wy) 几何光线（x、y 分别用 fx、fy）：y′ = y，u′ = u − y/f；EFL = −1/C，BFL = −A/C 圆形光斑位置：解 wx(z) = wy(z)（位于两束腰之间，即像散的“最小弥散圆”附近） 模型：薄透镜 / 薄反射镜、近轴；所有折叠限定为水平或竖直平面内，x、y 方向相互独立（像散主轴不旋转）。斜入射只计入像散（Coddington 关系），未计入彗差等高阶像差，入射角大时应改用离轴抛物面镜或实际光线追迹。正入射（θ = 0）时反射光沿原路返回，实际需配合分光镜或微小折转角。口径只用于计算透过率和截止光线，未计入硬边衍射。未计入热透镜、镀膜相位和装调误差，结果应以光斑仪实测确认。

公式与适用范围

模式求解：U² + W² = V²；U、W 由圆形阶跃光纤 LP 模式边界条件数值求根。 LP₀₁：U·J₁(U)/J₀(U) = W·K₁(W)/K₀(W) LPₗₘ：U·Jₗ₋₁(U)/Jₗ(U) + W·Kₗ₋₁(W)/Kₗ(W) = 0 V = (2πa/λ)√(n₁² − n₂²) θmax = asin(NA / n₀) F# ≈ 1 / (2 NA) 导模数：按求得的 LP 模式计数（LP₀ₘ 计 2，LPₗₘ(l≥1) 计 4），大 V 时 ≈ V²/2 截止：LP₀ₘ 为 J₁ 第 m−1 个零点，LPₗₘ 为 Jₗ₋₁ 第 m 个零点；λc = 2πa·NA / 2.405 MFD：Petermann II 定义 w² = 2∫ψ²r dr / ∫(dψ/dr)²r dr（与 ITU-T G.650、厂商规格一致） αbend = √π·κ²·exp(−(2/3)·γ³R/β²) / [eₗ·γ^(3/2)·V²·√R·Kₗ₋₁(W)·Kₗ₊₁(W)] κ = U/a，γ = W/a，β² = n₁²k² − κ²，e₀ = 2，eₗ≥₁ = 1（Marcuse 1976） 弱导近似下指数项 ≈ (4/3)·Δ·(W³/V²)·(R/a)，Δ = (n₁² − n₂²)/(2n₁²) 注意：指数项必须包含 Δ（Δ≈10⁻³ 量级），漏掉 Δ 会使损耗被低估上千个数量级。 α(dB/m) = 4.343 αbend 弹光修正：弯曲应力使折射率沿半径方向变化，公式中以等效半径 R_eff = k·R 代入，石英 k ≈ 1.28（Schermer & Cole 2007，p₁₁、p₁₂、ν 推得） 总损耗(dB) = α(dB/m) × L 适用范围：理想圆形阶跃型、弱导光纤；每个 LP 模式先由特征方程求 U/W，再用宏弯渐近式估算。LP₀₁ 结果最可靠；高阶模式在远离截止且弯曲半径明显大于纤芯半径时仅作趋势估算。未计入微弯、模式耦合、应力、温度、涂覆层、椭圆度和制造误差。实际光纤应以厂商曲线或实测校准。

公式与适用范围

基模高斯近似（Marcuse 1977），w = MFD/2： η_MFD = [2 w₁ w₂ / (w₁² + w₂²)]² η_offset = exp[−2 d² / (w₁² + w₂²)] η_tilt = exp[−2 (π n θ w₁ w₂)² / (λ² (w₁² + w₂²))] Loss(dB) = −10·log₁₀(η_MFD · η_offset · η_tilt) 精确重叠：η = |∫ψ₁ψ₂* dA|² / (∫|ψ₁|² dA · ∫|ψ₂|² dA)，ψ 为阶跃光纤 LP₀₁ 场（芯内 J₀，包层 K₀） MFD：Petermann II 定义，与光纤页一致；选“规格书 MFD”时直接使用输入值 多模满注入（几何光学，均匀模式分布）： 芯径项 = −10·log₁₀[(a₂/a₁)²]，仅 a₂ < a₁ 时计入 NA 项 = −10·log₁₀[(NA₂/NA₁)²]，仅 NA₂ < NA₁ 时计入 适用范围：理想阶跃型、弱导光纤，熔接点无间隙、端面平整；高斯近似对 V≈1.8–2.4 的单模光纤误差很小，V 偏离该范围时请参考精确重叠结果。LMA 光纤（V > 2.405）的结果为 LP₀₁ → LP₀₁ 的基模传输损耗；未耦合进出射光纤基模的功率会激发高阶模或进入包层，不一定全部损失，但会劣化光束质量。高斯模型的损耗对两个方向相同，实际 OTDR 单向测量会因 MFD 不同出现“增益/损耗”假象，需双向平均。未计入熔接拉锥、热扩芯、纤芯同心度、端面切割角和应力等因素。
